## 2. Rationale for Each Change

- **`select_book_page` in `Standby` and `Play` (`RUST-18`)**: TAS5805M / TAS5825M `BOOK_SELECT` (0x7F) is only valid when Page 0 is active. - **`try_start_playback_via_hiz` / `start_playback_via_hiz` (`RUST-17`)**: Executes the 4-step startup sequence (`CTRL2_MODE_HIZ` -> `FAULT_CLEAR_ANALOG` -> `CTRL2_MODE_PLAY_MUTE` -> `CTRL2_MODE_PLAY`) ensuring glitch-free startup transients while returning `Self` on error for bus ownership preservation (PERIPH-604).
