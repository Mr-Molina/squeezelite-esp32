## 3. Known Risks & Untested Assumptions
- Hardware touch behavior with real XPT2046 silicon relies on `configure_cyd_landscape` calibration values (`300..3800`). If physical touch screens differ in ADC calibration, `set_calibration()` or interactive calibration can be invoked.
- Watchdog timer is configured for a 10,000 ms Stage0 reset timeout and fed every 1 ms in the main loop; if the display driver hangs for >10 s, the hardware watchdog will cleanly reset the CYD controller.
