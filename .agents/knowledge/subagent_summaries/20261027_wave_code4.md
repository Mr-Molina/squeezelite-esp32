## 2. Rationale for Each Change

### 2.1 `hal.rs`
- **`CODE-HAL-FLASH-001`**: In `NvsFlashBackend::commit_store`, inserted `self.flash.erase_sector(target_sector)?;` immediately before `self.flash.write_sector(target_sector, &self.scratch)?;`. Flash NOR sectors cannot flip `0 -> 1` without a sector erase; writing without erasing corrupted the second sector in flash.
- **`GRS-012` Compliance**: Wrapped standalone comments to `<= 80` characters and code lines to `<= 100` characters.

### 2.2 `coordinator.rs`
- **`CODE-COORD-EOF-001`**: In `evaluate_state`, allowed state transition to `PlayerState::Stopped` + `self.pending_underrun = true` when `self.decode_complete_sent && (self.state == PlayerState::Playing || self.state == PlayerState::Buffering) && pipeline.output_buffer.available_read() == 0 && !pipeline.has_pending_pcm()`.
- **`CODE-COORD-SKIP-001`**: In `StreamCommandType::Unknown(b'a')` skip-ahead, updated frame calculation to 8 bytes per stereo frame (`frames.saturating_mul(8)`) and aligned to 8-byte boundary (`raw_bytes & !7`), and added unit test `test_strm_a_skip_ahead_8_bytes_per_stereo_frame`.
- **`CODE-COORD-SR-001`**: In `process_audio_step`, added sample rate synchronization: if `pipeline.sample_rate > 0 && pipeline.sample_rate != self.current_sample_rate`, update `self.current_sample_rate = pipeline.sample_rate`.

  - In `evaluate_state`: checked `!pipeline.has_pending_pcm()` before setting `self.decode_complete_sent = true`.

- **`CODE-COORD-TEST-001`**: Rewrote `test_flush_resets_buffer_threshold_and_exits_buffering` using a live loopback `SlimprotoClient` and real `handle_command(flush_cmd, ...)` execution.
