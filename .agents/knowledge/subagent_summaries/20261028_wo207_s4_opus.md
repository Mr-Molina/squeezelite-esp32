## 2. Rationale for Each Change
- **`no_std + alloc` Port**: Pure Rust Opus decoder integration for ESP32 without C toolchain dependencies or standard library dependencies, while keeping stack footprint small by boxing heavy decoder states.
- **Xtensa Backend Workaround**: Xtensa LLVM compiler lacks pattern matching for strength-reduced loop induction steps where the constant offset is 8192 (`DECODE_BUFFER_SIZE * 4`). Explicit conditional indexing for channels 0..2 avoids this compiler bug while preserving exact behavior.
- **Heap-Allocated CeltMode**: Moving `CeltMode` (25 KB) from static BSS in internal DRAM to heap memory allocated at first use restores `.stack` size from < 8 KB back to 36,288 B (safely exceeding the 36,000 B minimum requirement).
- **Firmware Integration**: Fully registers Opus codec with LMS via HELO `,ops` capability string and handles SlimProto `'u'` format dispatch.
